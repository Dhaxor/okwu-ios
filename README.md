# Okwu (iPhone app build mirror)

This repository holds only the Okwu iPhone app, so it can be built on GitHub's
free macOS runners. It is temporary and will become private.

**All rights reserved.** Source is visible for building only. No licence is
granted to copy, modify or redistribute it.

Dictionary data and recordings: Nkọwa okwu (Igbo API),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Used with
permission. Recordings trimmed, made mono and loudness-normalised by Okwu.
See `ATTRIBUTION.md`.

Builds: push to `release-build` for a signed App Store IPA, to `preview-build`
for a TestFlight-only IPA that includes draft lessons, or to `e2e-run` for a
simulator build plus the automated iPhone walkthrough.
